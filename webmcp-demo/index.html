Local WebMCP demo

Local only. This page registers two WebMCP tools, nothing leaves this page except the tool names and descriptions the extension reports, and only if you allow this origin in the Ollamapaca Chrome extension popup.

Serve it locally, then open it in Chrome:

python3 -m http.server 3000 in this folder, then open http://localhost:3000/

Chrome needs WebMCP on: Chrome 149 or later, origin trial, or chrome://flags/#enable-webmcp-testing enabled, then restart Chrome.
